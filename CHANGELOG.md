## 2.0.0-alpha.1

The starting point of Workhub 2, the Electron and TypeScript rewrite of Workhub. This version was
never tagged: it covers the history from 2026-10-27 to 2026-10-28, up to commit
[cd9e3f6](https://github.com/SoldierIced/workhub/commit/cd9e3f61e3e48cb9a90425e71ea4ac22823523c4).

### Features

* **core:** domain model, ports and versioned configuration; session groups, history and
  attention rules; usage budgets and the usage gate; account failover and hand-off briefs;
  notification policy; automations engine; chat watcher, health and pull request event domains.
* **agents:** Claude (native, on Workhub 1's Agent SDK bridge), Codex, Kiro, OpenCode, Gemini CLI
  and ACP agents, with transcript readers for the monitor and the history, per-account plan usage
  and Kiro credits.
* **sessions:** sessions in their own windows, session modes, model, agent and permission controls,
  queued messages, sub-agent and tool views, and sessions reopened on the next launch.
* **pull requests and tickets:** GitHub (gh) and GitLab (glab) code hosts, Jira and Linear trackers,
  Pull requests and Tickets screens and windows, and AI review before a pull request.
* **app:** Home, Health, Slack and Automations screens; tray popover, notifications and app icon
  badge; local diff review window; per-profile link opening; settings, appearance and opt-in
  update checks; import from Workhub 1.

### Performance

* **history:** share one session listing between concurrent lookups.
* **renderer:** render only what changed on a sidebar click or a streamed reply.
