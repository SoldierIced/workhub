# Keyboard shortcuts

On macOS the modifier is ⌘. On Windows and Linux use Ctrl in its place.

## Navigation

| Shortcut | Action |
|---|---|
| ⌘/Ctrl+1 | Home |
| ⌘/Ctrl+2 | Pull requests |
| ⌘/Ctrl+3 | Tickets |
| ⌘/Ctrl+4 | Slack (when the module is on) |
| ⌘/Ctrl+5 | Automations (when the module is on) |
| ⌘/Ctrl+6 | History |
| ⌘/Ctrl+8 | Health (when the module is on) |
| ⌘/Ctrl+0 | Sessions |
| ⌘/Ctrl+, | Settings |

## Sessions

| Shortcut | Action |
|---|---|
| ⌘/Ctrl+T | New session with the profile's preferred agent |
| ⌘/Ctrl+L | New session with the first agent in the File menu |
| ⌘/Ctrl+Y | New plain shell session |
| ⌘/Ctrl+Shift+N | Open the session in a new window |
| ⌘/Ctrl+Shift+W | Close the session |
| ⌘/Ctrl+Alt+1 / 2 / 3 | Show as App / Show as Console (Terminal) / Show as Shell |

## Composer

| Shortcut | Action |
|---|---|
| Return | Send |
| Shift+Return | New line |
| Esc | Interrupt the agent |
| Paste | Attach images |

## Other

| Shortcut | Action |
|---|---|
| Alt+↑ / Alt+↓ | Move the focused session or group up or down in the sidebar (also in its row menu) |
| ⌘/Ctrl+Return | Send all comments, in the **Review changes** window |
| ⌘/Ctrl+Alt+. | Stop reading aloud |
| Esc | Leave selection mode in Health |
| Zoom | View menu: reset zoom, zoom in, zoom out, full screen |

The key assigned to **New {agent} Session** in the File menu follows the agent order; only the first
agent gets ⌘/Ctrl+L.
